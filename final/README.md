## 접근 요약

| 모델 | 방식 | 단독 LB |
|---|---|---|
| **q_joint (내 모델)** | 로지스틱 + 날짜별 순위 피처 + **우측 중도절단 소프트 라벨** (`run_final.py --lag1feat --lag1q --q_joint`) | 0.7115 |
| sim (팀원) | 칼만 필터 수준 추정 + 급등 폭 반영 + 몬테카를로 구조 시뮬레이션 (`sim.py`) | — |
| T01 (팀원) | ranklearn 랭킹 모델 | 0.7032 |
| mate (팀원) | 0.8·sim + 0.2·T01 | 0.7395 |

### 1단계: 순위 블렌드

```
score = 0.70·rankpct(mate) + 0.20·rankpct(T01) + 0.10·rankpct(q_joint)
rr    = rankpct(score)
pred  = 1 / (1 + exp(-8 · (rr − 0.8)))      # 순서 보존 변환 (PR-AUC 불변, 0~1 보장)
```

PR-AUC는 순위만 평가하므로 각 모델 출력을 순위로 바꿔 섞는다. 판별(q_joint), 생성(sim), 랭킹(T01)으로 구조가 달라 틀리는 지점이 다르다.

### 2단계: 중도절단 규칙

**08-25 공식 정답 = 1** 이고 **08-25 ~ 08-31에 올린 롱폼이 0편**인 채널(9개) → 최상위로 (원래 순서 유지)

- 08-25 정답은 08-25 ~ 09-11 영상으로 매겨졌는데, 데이터는 08-31까지만 있다(중도절단된 관측).
- 관측 구간에 영상이 0편인데 정답이 1이면, 정답을 만든 영상은 09-01 ~ 09-11에 있고 테스트 창(09-01 ~ 09-26)에 그대로 포함된다.
- 테스트와 같은 구조(26일 창, 7일 전 18일 창 정답)로 07-25 ~ 08-05 백테스트 → 이 그룹의 다음 양성률 **77.5%** (전체 19%).
